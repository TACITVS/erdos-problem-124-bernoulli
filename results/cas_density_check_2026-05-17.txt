== 1. log_2 a <= a - 1 for a >= 3 ==
symbolic argument:
  f(a) = a - 1 - log_2 a
  f'(a) = 1 - 1/(a*log(2))
  f'(a) > 0 for a > 1/ln(2) = 1.442695 (< 3)
  f(3) = -log(3)/log(2) + 2 = 0.415037 > 0
  therefore f(a) > 0 for all a >= 3

numerical sweep a = 3..100: log_2 a <= a - 1 holds in all 98 cases
