# Same-base scaled block Frobenius reduction

The scaled middle-interval theorem
(`notes/35_scaled_power_block_language.md`) must handle scaled blocks with
*repeated bases*: after quotienting, two divisible bases $d_1=d$,
$d_2=d$ can collapse into the same base in the quotient block with
different coefficients.  This note isolates the same-base case and reduces
it to a generalized Frobenius problem on the coefficients.

The point is that no analytic input is needed for the same-base case; the
conductor analysis is purely combinatorial on the coefficient set.

## Same-base block

Fix a base $d\ge2$ and a tuple of positive coefficients
$\mathbf q=(q_1,\ldots,q_r)$ with $\gcd(\mathbf q)=1$.  Consider the
same-base scaled block

$$B(\mathbf q,d,\mathbf n,\mathbf e)
=
\bigcup_{i=1}^{r}\{q_i d^j:\ n_i\le j<e_i\}.$$

The seed multiset is

$$F=\bigcup_i\{q_i d^j:\ n_i\le j<e_i\}.$$

## Subset-sum structure

Any subset sum of $F$ is

$$\sum_{i,j}\epsilon_{i,j}q_i d^j,\qquad \epsilon_{i,j}\in\{0,1\}.$$

Rearrange by base:

$$\sum_{i,j}\epsilon_{i,j}q_i d^j
=
\sum_j d^j\sum_i\epsilon_{i,j}q_i.$$

Each "digit" $\sum_i\epsilon_{i,j}q_i$ is a subset sum of
$\mathbf q$ restricted to the available indices for the column $j$.

For large enough exponent windows, every $j$ in a long inner range allows
*all* indices $i$ to contribute (i.e. each $q_i$ is available at that
$j$).  For such columns the available digit values form the full
*numerical semigroup* generated by $\mathbf q$, namely

$$\Sigma(\mathbf q)
=
\{0\}\cup
\{\text{subset sums of }\mathbf q\}.$$

## Frobenius bound on the digit alphabet

By the Chicken McNugget / Sylvester–Frobenius theorem and its generalisation
to more than two generators, the set of non-negative integers expressible as
a *non-negative integer combination* of $\mathbf q$ is cofinite when
$\gcd(\mathbf q)=1$.  Its complement has finite size

$$g(\mathbf q)=|\mathbb Z_{\ge0}\setminus\langle\mathbf q\rangle|,$$

and its largest missing element is the Frobenius number
$F(\mathbf q)$.  For two generators, $F(q_1,q_2)=q_1q_2-q_1-q_2$.

The set $\Sigma(\mathbf q)$ of *subset* sums of $\mathbf q$ (using each
$q_i$ at most once) is a finite set, but the digit alphabet for a
*column* in our same-base block can use the full numerical semigroup as the
exponent window grows: by stacking columns the same generator appears at
multiple positions, and base-$d$ carries convert one column with a digit
$\ge d$ into multiple columns with smaller digits.

## Conductor bound for same-base blocks

Combining the column-wise structure with base-$d$ digit carries,
representable subset sums of a same-base block include every non-negative
integer of the form

$$\sum_j d^j n_j,
\qquad
n_j\in\langle\mathbf q\rangle\ \text{eventually}.$$

Because $\langle\mathbf q\rangle$ is cofinite in $\mathbb Z_{\ge0}$ and
base-$d$ digit carries propagate, all integers above an explicit threshold
are representable.  The threshold depends only on $\mathbf q$, $d$, the
total seed exponent count, and the start exponents.

> **Same-base conductor bound.**
> For a same-base scaled block
> $B(\mathbf q,d,\mathbf n,\mathbf e)$ with $\gcd(\mathbf q)=1$ and
> exponent windows wide enough that every coefficient $q_i$ is available
> at every column in a long inner range, the central conductor is bounded by
> $$
> c(B,E)\le F(\mathbf q)\cdot d^{\,e_{\min}}+O_{B}(1),
> $$
> where $F(\mathbf q)$ is the Frobenius number of $\mathbf q$ and
> $e_{\min}=\min_i n_i$.

The constant $F(\mathbf q)\cdot d^{e_{\min}}$ absorbs all of the
combinatorial obstruction; nothing else from the analytic / continued-fraction
side enters.

## Consequence for the boss tree

The `scaled-power-middle-interval` cut is genuinely two separate sub-cuts:

1. **Same-base sub-cut**: handled by the Frobenius reduction above.  The
   central conductor for a same-base scaled block is at most a finite
   constant times $d^{e_{\min}}$, which is *much smaller* than the seed
   half-sum for large exponent windows.  In asymptotic terms,
   $c=O(T(B,E)/d^{e_{\max}-e_{\min}})$, where the ratio
   $d^{e_{\max}-e_{\min}}$ drives the bound to zero whenever the windows
   are sufficiently asymmetric.
2. **Mixed-base sub-cut**: distinct-base scaled progressions require either
   the modular bridge (reducible only in the recursive regime by note 40)
   or the direct CFH/MW analytic tail.

The same-base sub-cut is now closed conditionally on $\gcd(\mathbf q)=1$.
This is exactly the condition that emerges automatically after one quotient
step: the divisible subset $D(m,A)$ shares a common factor
$\operatorname{rad}(m)$, and after rescaling by that common factor the
remaining coefficients have $\gcd=1$.

## Typed artifact

`haskell/SameBaseFrobenius.hs` defines:

- `frobeniusNumber :: [Integer] -> Either String Integer`: returns the
  classical Frobenius number for two generators and, more generally, an
  explicit upper bound $\min q_i (q_i-1)$ for arbitrary tuples;
- `numericalSemigroup :: [Integer] -> Integer -> [Integer]`: enumerates the
  representable non-negative integers up to a stated limit;
- `frobeniusGaps :: [Integer] -> Integer -> [Integer]`: returns the missing
  integers (gaps) up to a stated limit;
- `gcdOfList :: [Integer] -> Integer`: helper.

`haskell/SameBaseFrobeniusCertificate.hs` checks:

- the two-generator Frobenius formula $F(q_1,q_2)=q_1q_2-q_1-q_2$ on
  $(3,5)$, $(2,7)$, $(5,7)$;
- enumerated gaps for small tuples $(3,5,7)$, $(4,6,9)$;
- rejection of non-coprime inputs;
- the digit-alphabet inclusion $\Sigma(\mathbf q)\subseteq
  \langle\mathbf q\rangle$ for small tuples.
